# 《技术洞察周/双周报》草稿生成（面向技术管理层）

基于本期已聚合的「方向主题簇」「技术信号卡」「Stage 3 历史对照」以及同 L1/L2 关联的「行业新闻事件」，生成一份供人工审核发布的技术洞察草稿。

## 强制防幻觉纪律
1. **无证据不准写**：`executiveSummary`、`sections[].claims`、`emergingSignals` 中的每一条论断都必须绑定至少一个真实存在的 `signalIds`；严禁编造不在输入列表中的信号 ID、数字或公司动作。
2. **产业佐证分离**：如引用了新闻轨事件，将其 ID 放入 `relatedStoryIds`，明确区分“技术演进事实”与“产业/竞品动态”。
3. **管理层视角**：每条核心结论尽量落到「升温/拐点信号 + 建议动作（持续跟踪 / 安排技术调研 / 评估试点）」。
